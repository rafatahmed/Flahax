# Roadmap

Next work, in order: broader numerical and input-boundary testing, stable consumer contracts,
physical validation (a [protocol](../evidence/physical-validation-protocol.md) is in draft), and a
validated conductivity model for irrigation-strength solutions first and concentrated stock tanks
second.

FlahaX is developed as the chemistry engine for the FlahaFAST application, where it is planned to
provide formulation, pH and conductivity planning. That integration is not yet in place: FlahaFAST
does not currently import FlahaX, and FlahaX stays a standalone package with its own releases.

See the [development roadmap](https://github.com/rafatahmed/Flahax/blob/main/docs/development-roadmap.md),
the [current status](https://github.com/rafatahmed/Flahax/blob/main/docs/development-status.md) and the
[open issues](https://github.com/rafatahmed/Flahax/issues).
