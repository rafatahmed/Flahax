# Command line

This page shows the help of each command exactly as FlahaX prints it (generated by
`tools/cli_reference.py`). The JSON planning commands `flahax workflow`, `flahax ec` and
`flahax size` read a request on standard input, or ask for it with `--interactive`; see
[Site planning](../developer/site-planning.md).

## `flahax`

The entry point: every command, with examples.

```text
usage: flahax [-h] [--version] [--interactive] [COMMAND]

FlahaX: fertilizer recipe, pH and A/B stock tanks from your water and crop formula.

commands:
  mix        answer five questions and get tank A, tank B and the acid (growers, agronomists)
  batch      the same from files in one command, for scripts (flahax batch --help)
  recommend  read a JSON request on stdin and write a fertilizer recipe (the default)
  workflow   plan a full workflow from a JSON request on stdin, or with --interactive
  ec         screen the EC of supported products before acid (JSON on stdin or --interactive)
  size       size injector channel volumes and flows (JSON on stdin or --interactive)

positional arguments:
  COMMAND        one of the commands above (default: recommend)

options:
  -h, --help     show this help message and exit
  --version      show program's version number and exit
  --interactive  ask for the inputs of workflow, ec or size instead of reading JSON

Examples:
  flahax mix                        start a new batch, full screen in a terminal
  flahax mix sessions/tomato-ro     repeat a saved batch without questions
  flahax mix --plain                ask the questions line by line
  flahax batch --formula "Tomato (Howard Resh)" --water ro --ph 5.8 --acid HNO3:0.60:1.37 --output out
  flahax < request.json             write a recipe from a JSON request

Documentation: https://flahax.readthedocs.io/
Report a problem: https://github.com/rafatahmed/Flahax/issues
```

## `flahax mix`

Five questions to tank A, tank B and the acid, with a batch sheet.

```text
usage: flahax mix [-h] [--output OUTPUT] [--plain] [session ...]

``flahax mix``: five questions, then tank A, tank B and the acid.

    flahax mix                    ask the five steps, save the answers, write the sheets
    flahax mix sessions/NAME      run a saved session again without questions
    flahax mix --plain            ask line by line instead of the full-screen wizard

Steps: 1/5 specification (tanks, injection ratio, temperature, how stock is
prepared), 2/5 water analysis, 3/5 crop formula, 4/5 fertilizers and acids, 5/5
target pH. Defaults are shown in brackets; Enter keeps them. Typed items are saved
under ``$FLAHAX_HOME`` (else ``~/.flahax``) as files ``flahax batch`` reads, and only
once every step is answered: Ctrl+C or end of input saves nothing.

positional arguments:
  session          a saved session, e.g. tomato-ro (flahax mix sessions lists them)

options:
  -h, --help       show this help message and exit
  --output OUTPUT  new directory for the sheets (default: ./flahax-mix-<session>)
  --plain          line-by-line questions instead of the full-screen wizard
```

## `flahax batch`

The same from files in one command, for scripts.

```text
usage: flahax batch [-h] [--formula FORMULA | --crop CROP | --targets TARGETS] [--list-formulas]
                    [--water WATER] [--water-share PERCENT] [--volume VOLUME] [--ph PH]
                    [--ratio RATIO] [--acid FORMULA:FRACTION:DENSITY[:NAME]]
                    [--limit SYMBOL=MG_PER_L] [--max-reagent-litres MAX_REAGENT_LITRES]
                    [--products PRODUCTS] [--rules RULES] [--output OUTPUT]

``flahax batch``: one formula and one water to a report, a batch sheet and a JSON summary (#79).

Water is ``ro`` (no ions) or a JSON file::

    {"id": "well-104", "measured_ph": 7.8,
     "mg_per_litre": {"Ca": 244, "Mg": 100.8, "K": 44.2, "Na": 680, "Cl": 1280.4,
                      "S": 241.4, "N_NO3": 3.47, "HCO3": 197}}

Elements are mg/L of the element (S as S, N_NO3 and N_NH4 as N); ``HCO3`` is
the legacy equivalent-carbon input in mg/L as HCO3, not titrated alkalinity.
For a titration use signed ``alkalinity_meq_per_litre`` instead of HCO3.
Iron is taken as Fe(III), the form in aerated water.
Explicit final solvent mass/volume or solution density/nonwater mass define the
concentration basis. Legacy inputs report an unquantified 1 kg solvent/L assumption.

A value of 0 is a measured zero and stays zero (``"Cl": 0`` for chloride-free
water, ``"HCO3": 0`` for carbon-free water); an omitted ion is not measured, and
measured-pH chemistry needs ``HCO3`` (0 if none). Optional keys:
``"below_detection": {"Mn": 0.01}`` (detection limits, mg/L; taken as zero, never
adjusted), ``"balance_ion": "Cl"`` or ``"Na"`` and
``"balance_ion_uncertainty_percent": 10`` (the stated uncertainty of that ion).

Nutrient targets and concentration limits use the analysis exactly as entered.
For the chemistry only (pH, saturation, EC, reagent dose) the analysis is
speciated at its measured pH: used unchanged if it already balances, otherwise
closed on the balance ion, within its stated uncertainty, or as an assumption
flagged for review. The report shows both and never lets that balancing pass or
fail a limit (#84).

Limits are never assumed: declare each maximum with ``--limit Cl=106.35`` (mg/L in
the final solution); unspecified limits are not checked. Acids are never assumed
either: pass your certificate values with ``--acid``. The packaged bases (KOH 45%,
KHCO3, K2CO3) are always evaluated.

options:
  -h, --help            show this help message and exit
  --formula FORMULA     exact name of a packaged formula
  --crop CROP           text that matches exactly one packaged formula name
  --targets TARGETS     JSON file of target mg/L (N_NO3 and N_NH4 as N)
  --list-formulas       list the packaged formulas and exit
  --water WATER         "ro" or a water analysis JSON file (see above)
  --water-share PERCENT
                        use the analysed water as this percentage of the batch water, the rest
                        ion-free (desalinated or RO); default 100
  --volume VOLUME       final batch litres (default 1000)
  --ph PH               target feed pH (default 5.8)
  --ratio RATIO         final litres per litre of concentrate (default 100)
  --acid FORMULA:FRACTION:DENSITY[:NAME]
                        an acid from your certificate, e.g. HNO3:0.60:1.37; repeat for more
  --limit SYMBOL=MG_PER_L
                        a maximum concentration in the final solution, e.g. Cl=106.35; repeat for
                        more. Checked on the laboratory analysis; none is assumed
  --max-reagent-litres MAX_REAGENT_LITRES
                        largest reagent volume per batch (default volume/200)
  --products PRODUCTS   JSON array of your product records (default: the packaged catalogue)
  --rules RULES         JSON array of extra compatibilityRule records separating products
  --output OUTPUT       new directory for report.html, batch-sheet.html and summary.json
```
