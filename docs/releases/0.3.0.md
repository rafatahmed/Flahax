# FlahaX 0.3.0

Historical GitHub release record for the package published to PyPI on
**2026-09-27**. This GitHub record was published on **2026-10-01**; it is
not a new PyPI upload or a backdated GitHub publication.

## Included capabilities

- Fertilizer formulation with source-water nutrient subtraction.
- One bounded mixed-equilibrium model covering 28 catalogue products,
  197 aqueous entries and 28 phases.
- Fe-only DTPA and o,o-EDDHA catalogue forms, declared EDTA products and CH-micro.
- Nitric-acid target-pH and assay-qualified equilibrium-to-delivery planning.
- Sourced stock planning, measured-curve pH and calibrated pump-planning APIs.
- A shipped user manual, PHREEQC reference evidence and clean-install checks.

Runtime requirements: Python 3.11 or newer, no mandatory third-party Python
dependencies. PHREEQC is a separate verification tool, not bundled software.

## Scientific and release boundaries

The coupled model is limited to 25 C, Davies ionic strength at or below
0.1 mol/kg water, fixed oxidation states and the declared analytical/phase
boundary. Planning results are not autonomous dosing instructions, operational
certification or universal concentrated-stock predictions.

The owner authorized the original 0.3.0 PyPI publication using local evidence
despite the GitHub Actions billing blocker. That exception does not mean hosted
checks passed and does not apply automatically to later releases. Computational
assessment is attributed to Rafat Al Khashan; independent laboratory evidence
or a personal signature is not claimed.

The newer site-input CLI, EC-screening and graphical-report work belongs to
0.3.1 preparation and is **not** included in this release.
